# Management Dashboard

React + TypeScript + Vite demo app. There is no backend: all API calls are answered in the browser from dummy data.

## Run

Requires Node.js 20+.

```bash
npm install
npm run dev
```

Open the URL printed in the terminal (usually http://localhost:5173).

Demo login: `admin@example.com` / `password`

## Build

```bash
npm run build
```
